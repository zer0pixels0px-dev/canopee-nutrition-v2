# Athena – Pro Line (dry) & Blended (liquid)

> Source : athenaag.com + support Athena · Collecté : 2026-09-27

## Résumé
Marque pro / commercial très populaire. Deux lignes principales :
- **Pro Line** : poudres solubles (Pro Core, Pro Grow, Pro Bloom) – économique à grande échelle.
- **Blended** : liquides A+B (Grow A/B, Bloom A/B) + CaMg, PK, Cleanse, Fade, Balance.

Cibles EC élevées (jusqu’à 3,0) pour cultures intensives. Charts officiels Imperial / Metric, concentrate ou weight.

## Points essentiels

### Pro Line (recommandé pro)
| Produit | Rôle | Notes |
|---------|------|-------|
| Pro Core | Base Ca + micros (toute culture) | Calcium Ammonium Nitrate + micros |
| Pro Grow | Veg (N) | Pas d’urée / ammoniacal |
| Pro Bloom | Flower (P-K + micros) | Potassium sulfate (favorise terpènes) |
| Pro Balance | pH up / buffer RO | |
| Fade | Fin de cycle | |
| Cleanse | Nettoyage système | |

**Dosage concentrate (recommandé)** : stock ~2 lb/gal ou 226 g/L → doser ml/10 L selon EC cible (ex. EC 3,0 ≈ 90 ml Pro Grow/Bloom + 54 ml Core /10 L).

**Par poids (g/10 L)** : Pro Grow/Bloom ~20,3 g + Core 12,2 g en phases principales.

### Blended (liquide – plus simple)
- Grow A + Grow B (veg)
- Bloom A + Bloom B (flower)
- + CaMg 8–13 ml/10 L, Cleanse, PK (mid-late flower), Fade

EC cibles Blended : ~2,1 veg → 2,3–2,6 flower → descente.

### Formats
- Pro : sacs / seaux poudre (économiques)
- Blended : 1 L, 4 L, 20 L, etc.

### Warnings
- Pro Line : mélanger en concentrate d’abord pour précision.
- EC élevés → surveillance runoff et qualité d’eau.
- Cleanse / Fade selon schedule.
- Charts multi-langues disponibles sur support.athenaag.com.
