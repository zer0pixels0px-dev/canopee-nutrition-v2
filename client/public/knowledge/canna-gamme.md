# CANNA – Gammes Terra / Coco / Hydro / BioCanna

> Source : sites officiels CANNA + feed charts UK / international · Collecté : 2026-09-26/27

## Résumé
Leader hollandais. Lignes **spécifiques par substrat** (ne pas interchanger). A+B pour Coco et Hydro, mono-bouteille pour Terra. Additifs : Rhizotonic, Cannazym, CannaBoost, PK 13/14, Silica, etc. pH et EC stricts selon ligne.

## Points essentiels

### 1. CANNA TERRA (sol / potting mix)
- **Terra Vega** (croissance) → **Terra Flores** (floraison)
- pH cible solution : 5,8 – 6,2
- EC typique : 1,1 – 1,7 mS/cm
- Dosage indicatif (ml/10 L) :
  - Start : Rhizotonic 40 ml
  - Veg I : Terra Vega 15–35 ml + Rhizotonic 20 + Cannazym 25
  - Veg II : Terra Vega 35–55 + Boost 20
  - Gen I–III : Terra Flores 50–70 → 20–30 + PK 13/14 15 ml (1 semaine)
- Flush final : eau claire

### 2. CANNA COCO (coco coir)
- **Coco A & B** (même formule toute la culture – pas de switch Vega/Flores)
- Toujours **A puis B**, quantités égales
- pH : 5,5 – 6,2 (souvent 5,8)
- EC : 1,1 – 2,4 selon phase
- Dosage (ml/10 L) :
  - Start : A+B 15–25 + Rhizotonic 40
  - Veg : A+B 20–35 + Cannazym 25 + Boost
  - Flower : A+B 30–40 + PK 13/14 (1 sem) + Boost 20–40
- **Warning officiel** : « Do not mix A & B concentrate directly ; insoluble combinations will occur »

### 3. CANNA HYDRO (run-to-waste / inert)
- **Hydro Vega A+B** → **Hydro Flores A+B**
- Versions Hard Water / Soft Water
- pH : 5,2 – 6,2 (plus bas)
- EC plus serré
- Dosage (ml/10 L) : Vega 10–30 A+B → Flores 15–35 A+B + PK 15 ml

### 4. Additifs clés
| Produit | Rôle | Dose typique |
|---------|------|--------------|
| Rhizotonic | Stimulant racinaire (végétal) | 20–40 ml/10 L (début) |
| Cannazym | Enzymes (racines mortes) | 25 ml/10 L (dès sem. 2) |
| CannaBoost | Stimulateur floraison / photosynthèse | 20–40 ml/10 L |
| PK 13/14 | Spike P-K | 15 ml/10 L (1–2 semaines max mid-flower) |
| CANNA Silica | Silicium | selon label |
| pH- Grow / Bloom / pH+ | Ajustement | dernier |

### Analyses garanties (exemples labels)

**CANNA Coco A** (approx. NPK 4-0-1) : N 3.8 % (nitrate) · K₂O 0.7 % · CaO 6.3 % · MgO 0.6 % · Fe DTPA 0.02 % + fulvic.  
**CANNA Coco B** (approx. 1-4-2) : N 0.8 % · P₂O₅ 3.9 % · K₂O 2.2 % · MgO 1.8 % · S 1.8 % · micros B/Cu/Mn/Mo/Zn.  
**CANNA Terra Vega** : N 2.6 % · P₂O₅ 1.1 % · K₂O 3.1 % · Mg 0.6 % · S 0.2 % + micros chélatés.

### 5. Formats
- 1 L, 5 L, 10 L, 20 L (et plus grands pour pro)
- Substrats : Coco, Terra Professional, etc.

### Warnings CANNA
- Ne jamais mélanger A et B concentrés.
- Utiliser la bonne ligne selon substrat (Terra ≠ Coco ≠ Hydro).
- PK 13/14 seulement 1–2 semaines (excès → lockout Zn/Fe/Ca).
- Stocker à l’abri UV (chélates de fer).
