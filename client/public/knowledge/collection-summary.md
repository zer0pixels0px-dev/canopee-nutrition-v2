## Points clés transversaux
- **Jamais** mélanger concentrés A + B.
- Rester dans une même gamme de base.
- Ordre : Silice → CalMag → Base A → Base B → Additifs → pH dernier.
- Coco = CalMag quasi systématique (sauf formules déjà enrichies).
- PK boosters = fenêtre courte (1–2 semaines).
- Commencer à 50–75 % dose.
