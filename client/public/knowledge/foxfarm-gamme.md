# FoxFarm – Trio classique + Cultivation Nation & additifs

> Source : foxfarm.com (feeding schedules, product pages, FAQ) · Collecté : 2026-09-27

## Résumé
Gamme américaine très populaire, particulièrement adaptée sol et coco. Trio de base : **Grow Big** (veg) + **Tiger Bloom** (flower) + **Big Bloom** (organique, toute la culture). Versions Hydro spécifiques. Nombreux additifs Bush Doctor (Open Sesame, Beastie Bloomz, Cha Ching, Kangaroots, etc.). Charts officiels sol et hydro (12 semaines typiques).

## Points essentiels

### Bases principales
| Produit | N-P-K | Rôle | Notes |
|---------|-------|------|-------|
| Grow Big® | 6-4-4 (sol) / 3-2-6 (Hydro) | Croissance végétative | Formule Hydro différente (N mieux assimilable en hydro) |
| Tiger Bloom® | 2-8-4 | Floraison / buds | Dès premiers signes de fleurs → récolte |
| Big Bloom® | 0-0.5-0.7 | Organique, toute la culture | Earthworm castings + bat/seabird guano + rock phosphate + sulfate of potash magnesia. OMRI-friendly. Suspension (peut boucher pompes) |

### Dosages étiquette (généraux)
- **Grow Big** : 2–3 tsp (10–15 ml)/gal every other watering (general) ; 4 tsp heavy.
- **Tiger Bloom** : 2–3 tsp/gal every other watering ; 4 tsp heavy ; recirculating 2–3 tsp.
- **Big Bloom** : 4 Tbsp (60 ml)/gal every other watering ; heavy ½ cup (120 ml)/gal 1×/semaine ; foliar 1 Tbsp/gal.

### Schedule typique (sol – per gallon, tsp)
- Semaines 1–4 (18 h) : Big Bloom 6 tsp + Grow Big croissant (1→3 tsp) + additifs (Kangaroots, Wholly Mackerel, etc.).
- Semaines 5–12 (12 h) : Tiger Bloom 2–3 tsp + Big Bloom 1–3 Tbsp + Open Sesame / Beastie Bloomz / Cha Ching selon phase.
- Flush : SledgeHammer 2 tsp/gal (sol) ou 0.5 tsp (hydro).
- EC cibles approximatives : 0.3–0.6 (début) → 2.0–3.0 mid-flower → descente.

### Versions & substrats
- **Sol / soilless** : Grow Big (6-4-4) + Tiger Bloom + Big Bloom.
- **Hydro / coco** : Grow Big Hydro (3-2-6) + Tiger Bloom + Big Bloom + Kangaroots / Microbe Brew.
- Ne pas utiliser Grow Big sol en hydro (recommandation officielle).

### Additifs courants (Bush Doctor)
- Open Sesame®, Beastie Bloomz®, Cha Ching® (PK boosters)
- Kangaroots™, Microbe Brew™
- Cal-Mag, Kelp Me Kelp You, Wholly Mackerel, Bembé, Boomerang
- SledgeHammer (flush)

### Analyses garanties (exemples officiels)

**Grow Big® 6-4-4 (sol)**  
- Total N 6.0 % (2.9 % ammoniacal + 3.1 % nitrate)  
- P₂O₅ 4.0 % · K₂O 4.0 %  
- Mg 0.60 % (soluble)  
- B 0.02 % · Cu 0.05 % (chélaté) · Fe 0.10 % (chélaté) · Mn 0.05 % (chélaté) · Zn 0.05 % (chélaté)  
- Dérivé de : Ammonium Nitrate, Ammonium Phosphate, Potassium Phosphate/Nitrate, Earthworm Castings, Magnesium Nitrate/Sulfate, Potassium Sulfate, Iron/Mn/Zn/Cu EDTA, Sodium Borate.

**Tiger Bloom® 2-8-4** · **Big Bloom® 0-0.5-0.7** (P₂O₅ 0.50 % · K₂O 0.70 % · Fe 0.10 % – dérivé earthworm castings, bat/seabird guano, rock phosphate, sulfate of potash magnesia).

### Formats
- Pint, quart, gallon, 2.5 gal, 5 gal, etc.
- Poudres pour certains boosters.

### Warnings officiels
- **Less is more** – overfeeding burns.
- pH 5.8–6.3 (hydro/coco) ; sol plus large.
- Big Bloom = suspension → risque de colmatage pompes.
- Grow Big sol ≠ Grow Big Hydro.
- Charts conçus pour indoor contrôlé ; outdoor = ajuster selon conditions.
- Flush 1–2 semaines avant récolte (plantes comestibles).
- Stocker correctement ; garder hors de portée des enfants.
